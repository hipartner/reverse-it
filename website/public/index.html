Inspect Any Application.
Uncover The Hidden Logic.

The unified reverse-engineering CLI and Model Context Protocol (MCP) server for JavaScript, Electron, and web applications. Turn compiled assets into verified evidence.

bash — npm install & analyze
npx -y ri-agents analyze /path/to/app
🔍

Module Dependency Graph

Deconstructs complex JavaScript bundles and unpacked directories to discover full imports, exports, and re-export trees with complete evidence provenance.

⚡

Electron IPC Analysis

Identifies all ipcRenderer calls, ipcMain listeners, channels, handlers, and BrowserWindow preload configurations.

🗺️

Source Map Unpacking

Inspects both inline Base64 source maps and external .map links to recover original source paths, filenames, and unminified code.

🤖

Built for AI Coding Agents

Full Model Context Protocol (MCP) support over stdio. Connects natively to Claude Code, Cursor, Codex, and Gemini CLI with clean structured contracts.

🛡️

Fail-Closed & Local-Only

Pure static parsing using Acorn. No cloud dependencies, no external RPCs, and never executes untrusted target binary bytes.

💻

Dual CLI Commands

Fast command-line workflows with both ri and reverse-it aliases, pretty terminal diagnostics, and machine-readable JSON modes.
